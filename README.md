# liblmdb

### This is a fork of [openldap/liblmdb](https://git.openldap.org/openldap/openldap/-/tree/mdb.master).

The source files have been refactored/reordered so that it "looks like" a source tree of a
project that I would make.

### Build
```console
make
```
> This will create a `liblmdb.so` and a `liblmdb.a` file
